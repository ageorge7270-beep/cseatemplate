Canva Import & Editing Guide
How to Use This Template in Canva
  1. Open Canva → Create a design → Select US Letter (8.5 × 11 in)
  2. Use this HTML file as your visual layout brief — refer to it in a second browser window as you build
  3. For each page, add a new Canva slide/page matching the layout shown
  4. Replace all [REPLACE …] placeholders with actual 2026 content
  5. Swap all grey image boxes with real photos (Capitol, members, rallies, etc.)
  6. Update all [XXXX] bill numbers, stat figures, and names
  7. To print directly from this HTML: use browser Print → Save as PDF (set paper to US Letter, no margins)
Design System
Navy: #0D1F3C (primary background, headers)
Gold: #C8963E (accents, stats, callouts)
Red: #B92B27 (Federal Issues section)
Green: #2A7A4B (bills supported, checkmarks)
Off-white: #F5F3EE (content page background tints)
Display font: Playfair Display (covers, titles)
Headline font: Barlow Condensed (section heads, stats)
Body font: Barlow (body copy, bullets)
Tip: All three fonts are free on Google Fonts. Search "Playfair Display", "Barlow Condensed", and "Barlow" in Canva's font browser.
